# BMS Smart IR

ИК-интеграция Home Assistant от **BMS Smart Home**: кондиционеры и телевизоры,
которыми управляют ИК-передатчики Broadlink (RM4 mini, RM4C mini, RM4 pro), плюс
ИК-хабы Tuya через облако.

Главное в версии 2: **панель в сайдбаре** и **новое ядро связи**, рассчитанное на
объект с десятками передатчиков.

## Панель «BMS ИК-пульты»

Появляется в боковом меню Home Assistant. На русском.

- **Обзор** — все передатчики: состояние связи, модель, сколько приборов
  привязано, температура и влажность с их встроенного датчика, счётчики команд.
- **Карта связей** — что к какому передатчику привязано, одним экраном.
- **Устройство** — характеристики, статистика (отправлено, потеряно, склеено
  повторов, переподключений), графики температуры и влажности за сутки, полоса
  наличия связи, список приборов с их состоянием.
- **Добавить** — поиск Broadlink в сети (или проверка по адресу), выбор типа,
  марки и модели с поиском по каталогу, тестовый сигнал на живой прибор, имя и
  комната. Всё в пять шагов, без YAML.
- **Обслуживание** — замена сломанного передатчика: приборы переезжают на новый
  адрес, сохраняя сущности, историю и сценарии.

## Ядро связи

Один Broadlink — одно соединение, общее для всех приборов перед ним.

- **Очередь с паузой** между ИК-посылками: залп из тридцати команд уходит
  полностью и по порядку, а не тонет в передатчике.
- **Склейка повторов состояния**: пока крутят температуру, уходит одна команда с
  итоговым значением. Нажатия кнопок (громкость, каналы) не склеиваются никогда.
- **Честный откат**: команда, не дошедшая до передатчика, возвращает интерфейс в
  прежнее состояние вместо того, чтобы показывать несуществующее.
- **ИК не переотправляется** после таймаута — повтор ИК-команды физически
  повторяет действие. Исключение — ответ «ключ протух»: он доказывает, что
  команда не выполнена.
- **Один таймаут не рвёт сессию** (нужны три подряд), сторож каждые 30 секунд
  поднимает устройства без активной задачи подключения, мягкий backoff,
  grace-период на короткие пропадания Wi-Fi.
- **Разнесённый старт** и потолок одновременных обращений — шестьдесят
  передатчиков не забивают Home Assistant при запуске.

Каждый пункт закреплён тестом (`tests/`), который гоняется против симулятора
Broadlink, говорящего на настоящем протоколе.

## Установка

**HACS:** Custom repositories → URL этого репозитория, тип **Integration** →
ADD → Download → перезапуск Home Assistant. Установка идёт из GitHub Releases,
поэтому нужен опубликованный релиз с тегом и публичный репозиторий.

**Вручную:** скопировать `custom_components/bms_smart_ir` в
`/config/custom_components/` и перезапустить Home Assistant.

Первый прибор добавляется через Settings → Devices & Services → Add Integration
→ **BMS Smart IR** (панель появляется в сайдбаре после этого). Дальше удобнее
добавлять из панели.

## Требования

- **Broadlink:** передатчик в одной сети с Home Assistant. Коды кондиционеров
  скачиваются из базы SmartIR один раз при добавлении и остаются в
  `<config>/bms_smart_ir_codes/` — при работе интернет больше не нужен. Коды
  телевизоров (55 моделей) входят в комплект.
- **Tuya:** настроенная интеграция `bms_integration` с облачным аккаунтом Tuya и
  включённый **IR API** в проекте Tuya IoT.

## Стенд для разработки

Виртуальные Broadlink, которыми управляет настоящая библиотека `broadlink`:

```bash
python tools/broadlink_sim.py --count 60 --json devices.json
```

Тесты (симулятор, ядро, нагрузка на 60 устройствах, сущности, панельный API):

```bash
pip install -r requirements-test.txt && pytest
```

Витрина панели без Home Assistant — `tools/panel_preview.html` (открывается
любым статическим сервером, показывает светлую и тёмную темы).

## Обновление с версии 1

Проходит автоматически при первом запуске: у записей появляется порт, а
дубликаты датчиков температуры и влажности (старая версия создавала их для
каждого прибора на одном передатчике) удаляются, кроме одной пары. Имена
сущностей, история и сценарии не меняются.
